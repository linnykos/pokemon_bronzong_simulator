# Brock's Scouting

- **Set / number:** Journey Together (JTG) #146
- **Regulation mark:** I — **Standard 2026 legal**
- **Category:** Trainer — **Supporter**
- **In decklists:** none yet — imported as a **candidate**.

## Effect

> Search your deck for up to 2 Basic Pokémon or 1 Evolution Pokémon, reveal them,
> and put them into your hand. Then, shuffle your deck.

## Notes for the simulator

A **choice of two modes**, exclusive — either up to 2 Basics, or exactly 1
Evolution, never a mix. The policy must pick a mode, and the right mode differs
sharply by turn.

### It is the only non-Ultra-Ball way to find Latias ex

The search is unrestricted by HP or Rule Box, so unlike the deck's other search
cards it can find **Latias ex**:

| Search card | Can find Latias ex? | Puts it where? |
|---|---|---|
| Poké Pad | no — Rule Box | hand |
| Buddy-Buddy Poffin | no — 210 HP | Bench |
| Telepathic Psychic Energy | no — not a Basic `[P]`… it *is* Psychic, so **yes** | Bench |
| Ultra Ball | yes, for 2 discards | hand |
| **Brock's Scouting** | **yes, free** | **hand** |

In **Basics mode** it can fetch **Bronzor + Latias ex in one card** — the exact
pair the turn-1 line wants: the evolving Basic, plus the free-retreat enabler that
gets it Active. That is the strongest thing this card does for this deck.

### Mode choice by turn

- **Turn 1:** Basics mode. Bronzor + Latias ex, or Bronzor + a second Basic.
- **Turn 2:** Evolution mode, fetching **Bronzong** — a strictly worse Hilda,
  which fetches Bronzong *and* an Energy. Only better than Hilda when the Energy
  is already in hand.

### It puts cards in the hand, not on the Bench

This distinguishes it from Buddy-Buddy Poffin and Telepathic Psychic Energy, and
cuts both ways. Benching from hand is free and unlimited, so it is rarely a cost —
**but Meowth ex's Last-Ditch Catch triggers only when Meowth ex is played from
hand onto the Bench**, so a Basic that arrives in hand can still trigger it, while
one that arrives directly on the Bench cannot.

### Competes for the Supporter slot

Like every Supporter here it is unplayable on turn 1 going first, and it contests
the once-per-turn slot with Hilda, Salvatore, Lillie's Determination, Surfer, and
Ciphermaniac's Codebreaking. That slot is now badly oversubscribed — six Supporters
want it and the deck gets one per turn. Quantifying that contention is part of what
part 6 should measure.
