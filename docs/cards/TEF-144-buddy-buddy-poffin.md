# Buddy-Buddy Poffin

- **Set / number:** Temporal Forces (TEF) #144
- **Regulation mark:** H
- **Category:** Trainer — **Item**
- **In decklists:** none yet — imported as a **candidate**.

## Effect

> Search your deck for up to 2 Basic Pokémon with 70 HP or less and put them
> onto your Bench. Then, shuffle your deck.

## Notes for the simulator

**A free Item that puts two Basics straight onto the Bench** — no discard cost,
unlike Ultra Ball. Potentially the strongest consistency card available to this
deck, but the 70 HP cap decides everything.

### Which Basics it can fetch

| Card | HP | Fetchable? |
|------|----|------------|
| **Bronzor TEF 68** | **80** | **NO** |
| **Bronzor PRE 66** | **70** | **yes** |
| **Bronzor SSP 126** | **60** | **yes** |
| Duskull PRE 35 | 60 | yes |
| Buneary PFL 83 | 70 | yes |
| Budew ASC 16 | 30 | yes |
| Flutter Mane TEF 78 | 90 | no |
| Meowth ex POR 62 | 170 | no |
| Latias ex SSP 76 | 210 | no |
| Mega Kangaskhan ex MEG 104 | 300 | no |

**This is the whole point of the alternate Bronzor printings.** As long as the
list runs Bronzor **TEF 68**, Buddy-Buddy Poffin cannot find the one Basic the
deck most needs. Swap to PRE 66 or SSP 126 and Poffin becomes a two-for-one that
fetches Bronzor *and* a Duskull.

- Puts them on the **Bench**, never the Active spot — so like Telepathic Psychic
  Energy, it fixes "no Bronzor", not "Bronzor isn't Active".
- An **Item**, so it is live on turn 1 **going first** (unlike every Supporter),
  which is exactly the branch where the deck is otherwise weakest.
- Also an Item, so it is shut off by an opposing Budew's Itchy Pollen.
