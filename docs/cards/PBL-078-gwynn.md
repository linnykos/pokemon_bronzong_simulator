# Gwynn

- **Set / number:** Pitch Black (PBL) #78
- **Regulation mark:** J
- **Category:** Trainer — **Supporter**

## Effect

> Discard up to 2 Pokémon that don't have a Rule Box from your hand, and draw 3
> cards for each card you discarded in this way. (Pokémon ex, Pokémon V, etc.
> have Rule Boxes.)

## Notes for the simulator

- **A draw Supporter with a cost the other draw Supporters do not have.**
  Lillie's Determination shuffles the hand into the deck and draws 8 for free;
  Gwynn draws **up to 6** and pays for it in Pokémon that leave the game. So the
  question it raises is which Pokémon are spare, and that is the Ultra Ball
  never-discard list again: the line is not spare, and a Bronzor without a
  Salvatore in hand is not spare either.
- **Discarding nothing is legal** — the text reads "up to 2" — and then it draws
  nothing at all. So a Gwynn played on a hand holding no spare Pokémon spends the
  Supporter slot for zero cards, and it is worth the slot only when at least one
  discardable Pokémon is held.
- **It does not shuffle**, which makes it the only draw Supporter that is safe
  while a Ciphermaniac's stack is pending. Neither list that runs it runs a
  Ciphermaniac's, so that never arises today.
- It cannot discard a **Latias ex**, **Meowth ex**, **Mega Lopunny ex**, **Mega
  Kangaskhan ex** or **Blissey ex** — every one of those has a Rule Box.
