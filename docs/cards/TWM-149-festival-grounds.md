# Festival Grounds

- **Set / number:** Twilight Masquerade (TWM) #149
- **Regulation mark:** H
- **Category:** Trainer — **Stadium**
- **Appears in:** decklist3 (1).

## Effect

> Each Pokémon that has any Energy attached (both yours and your opponent's)
> recovers from all Special Conditions and can't be affected by any Special
> Conditions.

## Notes for the simulator

- Protects an Energy-bearing Bronzong from Sleep/Paralysis, which would
  otherwise stop it attacking. Relevant only if the opponent model can inflict
  Special Conditions — it cannot in the `clear` or `item_lock` scenarios, so it
  is **inert for the current metric**.
- Model as a playable Stadium occupying the Stadium slot.
