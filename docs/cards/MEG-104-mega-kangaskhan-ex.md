# Mega Kangaskhan ex

- **Set / number:** Mega Evolution (MEG) #104
- **Regulation mark:** I
- **Category:** Pokémon — **Basic** (confirmed: does *not* evolve from
  Kangaskhan; decklist1 correctly contains no Kangaskhan)
- **Type:** Colorless
- **HP:** 300

## Ability

**Run Errand**
> Once during your turn, if this Pokémon is in the Active Spot, you may use
> this Ability. Draw 2 cards. You can't use more than 1 Run Errand Ability each
> turn.

## Attacks

**Rapid-Fire Combo** — `[C][C][C]` — 200+ damage
> Flip a coin until you get tails. This attack does 50 more damage for each
> heads.

## Other

- **Weakness:** Fighting x2 | **Resistance:** none | **Retreat cost:** 3

## Notes for the simulator

- A **Basic**, so it can be placed during setup and its Ability is live on
  turn 1 — no evolution delay.
- **Run Errand requires it to be Active.** Drawing 2 on turn 1 therefore
  conflicts directly with having Bronzor Active. Retreat cost 3, but Latias
  ex's Skyliner makes it free (it is a Basic), so the line "lead Mega
  Kangaskhan ex → Run Errand → free-retreat into Bronzor" is available *if*
  Latias ex is on the Bench. This is one of the most important interactions in
  the deck and the decision tree must model it.
- **[UNVERIFIED]** Prize cards given up when Knocked Out (rule box not shown on
  the source page). Irrelevant to the turn-2 target event.
