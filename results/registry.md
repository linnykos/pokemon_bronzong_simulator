# The decklist registry

Written by `scripts/score_decklists_claude.R` on 2026-08-30. **1000 replicates per cell**, seeds 1-1000 in every cell, so a difference between two decklists in the same row is a difference in the sixty cards rather than in the shuffles.

**The primary outcome is one fixed bar: Evolution Jammer on or before the player's own turn 2** (ADR 0004), identical going first and going second. Going first and going second are separate numbers and are never pooled (ADR 0002), which is why there are three tables below and not one.

**Mulligans are never a miss** (ADR 0005); the mulligan rate is beside the hit rate, not inside it. The **on turn 1** column is the only place Salvatore's speed appears, because the primary outcome deliberately prices a turn-1 kill and a turn-2 conventional line the same.

There is no going-second `item_lock` cell: Itchy Pollen is an attack and only a player who went second can use it, so the lock can only ever land on us when **we** went first.

The unmet counts are over the SET of open sub-goals, so a miss appears in
every column it belongs to and the columns sum to more than the miss count.

**Read the noise floor before ranking anything.** At 1000 replicates the standard error on a single rate near 75% is about **1.4 points**, and on the difference between two decklists about **2.0** — the seeds are shared but the decks are not, so the shuffles are effectively independent and the pairing buys little. **A gap under about 4 points is not resolved by this run.** The tables below are ordered by rate because they have to be ordered by something; the order inside a 4-point band is noise, and separating that band is exactly what raising the replicate count is for.

`results/registry_notes.md` is the hand-written reading of these tables. It is not regenerated by this script and will not be overwritten by it.

## The traces

One file per decklist, `results/<decklist>_traces.txt`, from the going-second `clear` cell. **Never compute a rate from one** (ADR 0006): the sample is roughly 12:3 misses to hits by construction, because a hit teaches nothing about what to change. Each file leads with the true rates for that reason.
